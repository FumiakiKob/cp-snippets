# cp-snippets

競技プログラミング（AtCoder等）で使用するコードスニペットおよびテンプレート集です。

## 概要
- 各種コンテスト（ABC / ARC / AHC等）で使用するデータ構造、アルゴリズム、入出力テンプレート等を管理してゐます。
- 短期 AHC をはじめとするコンテストの生成AI利用ルールに基づき、コンテスト開始前に作成・整備したコードの事前公開を兼ねてゐます。

## ファイル構成
- `.vscode/scheme.code-snippets`: VS Code 用 Scheme (Chez Scheme / Gauche) スニペット集
- `.vscode/duckdb.code-snippets`: VS Code 用 SQL (DuckDB) スニペット集

## ライセンス / 利用について
個人利用およびコンテスト提出コードへの引用を目的としてゐます。
